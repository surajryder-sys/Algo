# Claude context for this repo

These are the previous Claude assistant's saved "memory" notes (copied from `~/.claude/projects/.../memory/` on the
owner's PC on 30 Sep 2026) so that a teammate or a new Claude account can pick up with the same context.

- `MEMORY.md` is the index (one line per note).
- `feedback_*.md` = how the user wants to work (IST times, versioned EA files, discuss-first, no GUI actions, clean up
  scratch files, ...). Follow these.
- `project_*.md` = project history and decisions. The most relevant for current work:
  `project_v6s_ict_ea.md` (V6S-ICT EA, every version and test) and `project_v6s_ict_btc.md` (BTC/ETH/USOIL tests).
- Start with `v6s_ict/HANDOVER.md` for the current state of the V6S-ICT EA.

To give a new Claude Code session the same memory, copy these files into that machine's
`~/.claude/projects/<project-folder>/memory/` directory (keep `MEMORY.md` as the index).
Secrets are NOT here: credentials live only in the git-ignored `.env`.
